# aravind.log

A minimal static personal blog.

## Open it
Just open `index.html` in your browser.

## Add a new post
1. Copy one of the files inside `posts/`.
2. Change the title, date, and article text.
3. Add a new post row to `index.html`.

## Customize links
Search for:
- `https://github.com/`
- `https://www.linkedin.com/`
- `hello@example.com`

and replace them with your real details.

## Publish
This works well with GitHub Pages, Netlify, Vercel, or any basic static hosting.
